# Changelog

## 0.2.0 — 2026-08-16

Measured offline simulation-pilot release.

- Added 150-task exact-state dataset and fixed 60-task evaluation subset.
- Executed 16,560 episodes across four topologies and six experiments.
- Added severity-aware fault injection, application/consumption integrity, lineage propagation, attribution evidence views, verification, recovery, and reliability–cost analysis.
- Added task-clustered confidence intervals, paired tests, effect sizes, Holm correction, and explicit H1–H6 decisions.
- Added eight measured tables, six empirical figures, raw traces, reproducibility manifests, tests, CI, data/fault documentation, and methodology review.
- Classified H1 as mixed, H2–H3 as supported, and H4–H6 as not supported.
